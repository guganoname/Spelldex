# @spelldex/lore

Kuratierte Lore-Inhalte (Deutsch, eigene Formulierung). Layout: `content/<planes|creature-types|characters|events>/<id>.json`, `content/set-planes.json`.

- `status: draft` bis redaktionell geprüft; die App kennzeichnet Entwürfe.
- Quellen sind nur Verweise (`referenceOnly: true`). Das MTG Wiki steht unter CC BY-NC-SA 4.0, deshalb wird kein Text von dort übernommen.
- `facts` (Größe, Gewicht, Alter ...) nur mit kanonischer Quelle, nie erfunden.
